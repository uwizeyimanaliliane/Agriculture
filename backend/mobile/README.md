# Mobile app run notes

To run this app locally in Expo Go:

1. From the mobile folder, run:
   npm install
   npx expo start
2. Open the Expo Go app on your phone or start an emulator.
3. Scan the QR code shown in the terminal.

If you see a "No development build" error, this project now avoids the development-build-only Google Sign-In dependency and should run in Expo Go.
